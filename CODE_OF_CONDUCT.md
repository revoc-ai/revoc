# Code of Conduct

REVOC adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to all project spaces — issues, pull
requests, discussions, reviews — and to anyone representing the project.

In short: be respectful and constructive, assume good faith, and keep
criticism focused on ideas and code rather than people. Harassment,
discriminatory language, personal attacks and publishing others' private
information are not acceptable.

## Reporting

Report a violation privately to the maintainers:

- Use **Report content** (the `…` menu on any comment, issue, pull request or
  discussion) and choose **Report to repository admins**. Only the maintainers
  see these reports.
- For anything that cannot be reported that way, use GitHub's
  [Report abuse](https://github.com/contact/report-abuse) form.

Reports are handled confidentially. Maintainers will review every report,
respond to the reporter, and apply the enforcement guidelines of the
Contributor Covenant (correction, warning, temporary ban, permanent ban) as
appropriate.
